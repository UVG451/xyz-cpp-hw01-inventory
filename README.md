# ДЗ 1. Учет мячей

Ввод артикула от 0 до 19. Команды 1–3 добавляют, списывают и показывают остаток по артикулу. Команды 4–5 показывают общий остаток и пустые позиции. Команда 0 завершает программу.

## Сборка и запуск

Из командной строки Visual Studio 2022 с установленным CMake:

```powershell
cmake -S . -B build
cmake --build build --config Release
./build/Release/BallInventory.exe
```

Для проверки введите 1 и 19, затем 3 и 19. Остаток должен быть равен единице. После команды 2 для этого же артикула остаток обнулится. Попробуйте также артикулы 20, -1 и abc.
